uf.templates#

HTML template generation for uf web interface.

Provides functions to generate the web UI that lists functions and displays RJSF forms for interacting with them.

uf.templates.generate_index_html(function_specs, *, page_title='Function Interface', custom_css=None, rjsf_theme='default', base_url='')[source]#

Generate HTML page with RJSF forms for functions.

Creates a single-page application with:

  • Function list/navigation sidebar

  • RJSF form for selected function

  • Result display area

  • Uses React and RJSF from CDN (no build step required)

Parameters:

  • function_specs (Mapping) – Mapping from function names to their specs

  • page_title (str) – Title for the HTML page

  • custom_css (Optional[str]) – Optional custom CSS to inject

  • rjsf_theme (str) – RJSF theme to use (‘default’, ‘material-ui’, ‘semantic-ui’)

  • base_url (str) – Base URL for API endpoints

Return type:

str

Returns:

Complete HTML string for the web interface
