uf.specs#

Function specification management for uf.

Provides a Mapping-based interface to function specifications, including RJSF form specs and OpenAPI schemas.

class uf.specs.FunctionSpecStore(funcs, *, rjsf_config=None, ui_schema_factory=None, param_to_prop_type=None, validate=False)[source]#

Bases: Mapping

A mapping from function names to their RJSF specifications.

Lazily generates and caches form specs for each function.

Parameters:

  • funcs (Union[Iterable[Callable], Mapping[str, Callable]]) – Iterable of callables to generate specs for (named by name_of_func: __name__, the wrapped function’s for a functools.partial, the class name for a callable instance), or a mapping {name: callable} to name them explicitly

  • rjsf_config (Optional[dict]) – Optional configuration dict for RJSF generation

  • ui_schema_factory (Optional[Callable]) – Optional callable to customize UI schema generation

  • param_to_prop_type (Optional[Callable]) – Optional callable to map parameters to property types

  • validate (bool) – If true, every function is checked and its spec generated at construction, so a callable uf can’t build a form for fails there, naming it, rather than on the first request (default false: checked on first access of its spec; mk_rjsf_app validates).

Example

>>> def add(x: int, y: int) -> int:
...     '''Add two numbers'''
...     return x + y
>>> specs = FunctionSpecStore([add])
>>> 'add' in specs
True
>>> spec = specs['add']
>>> 'schema' in spec
True

dict
