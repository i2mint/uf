uf.organization#

Function grouping and organization for uf.

Provides tools for organizing functions into categories, groups, and hierarchies for better navigation in the UI.

class uf.organization.FunctionOrganizer[source]#

Bases: object

Organize functions into groups and hierarchies.

This class provides a fluent interface for building function organization structures that can be used to generate grouped navigation in the UI.

Example

>>> def user_create(name: str): ...
>>> def user_delete(name: str): ...
>>> def generate_report(): ...
>>> organizer = FunctionOrganizer()
>>> g = organizer.group('Admin', [user_create, user_delete], icon='shield')
>>> g = organizer.group('Reports', [generate_report], icon='file')
>>> [group.name for group in organizer.get_groups()]
['Admin', 'Reports']

>>> def create(): ...
>>> create.__module__ = 'myapp.user_ops'
>>> def generate(): ...

>>> organizer = auto_group_by_module([create, generate])

['Report Ops', 'User Ops']
uf.organization.auto_group_by_prefix(funcs, separator='_')[source]#

Automatically group functions by name prefix.

Groups functions based on the part of their name before the separator. For example, with separator=”_”:

  • user_create, user_delete → “user” group

  • report_generate, report_export → “report” group

Parameters:

  • funcs (Iterable[Callable]) – Functions to organize

  • separator (str) – Separator character (default: “_”)

Return type:

FunctionOrganizer

Returns:

FunctionOrganizer with auto-generated groups

Example

>>> def user_create(): ...
>>> def user_delete(): ...
>>> def report_generate(): ...
>>> def admin_reset(): ...
>>> funcs = [user_create, user_delete, report_generate, admin_reset]
>>> organizer = auto_group_by_prefix(funcs)
>>> [group.name for group in organizer.get_groups()]
['Admin', 'Report', 'User']
