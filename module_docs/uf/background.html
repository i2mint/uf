uf.background

Background task execution for uf.

Provides decorators and utilities for running tasks in the background, with support for queues, scheduling, and progress tracking.

class uf.background.PeriodicTask(func: Callable, interval: float, args: tuple = (), kwargs: dict | None = None)[source]

Task that runs periodically.

Example

>>> def cleanup():
...     print("Cleaning up...")
>>>
>>> periodic = PeriodicTask(cleanup, interval=3600)
>>> periodic.start()
>>> # Runs every hour
>>> periodic.stop()

class uf.background.TaskQueue(num_workers: int = 1, max_queue_size: int = 100)[source]

FIFO queue for background tasks.

Example

>>> task_queue = TaskQueue(num_workers=2)
>>> task_queue.start()
>>> task_id = task_queue.submit(expensive_function, x=10, y=20)
>>> status = task_queue.get_status(task_id)
>>> result = task_queue.get_result(task_id)

Decorator function

Example

>>> @background()
... def send_email(to: str, subject: str):
...     # Long-running email sending
...     pass
>>>
>>> task_id = send_email('user@example.com', 'Hello')
>>> # Returns immediately with task_id
