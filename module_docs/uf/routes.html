uf.routes

API routes for uf web interface.

Provides convenience routes for the web UI, including function listing, spec retrieval, and the main HTML interface.

uf.routes.add_ui_routes(app: Any, function_specs: Mapping, *, page_title: str = 'Function Interface', custom_css: str = None, rjsf_theme: str = 'default') → None[source]

Add UI routes to a qh app.

Adds the following routes: - GET / : Main UI page (HTML) - GET /api/functions : List available functions (JSON) - GET /api/functions/{name}/spec : Get RJSF spec for function (JSON)

Parameters:

  • app – The qh/bottle/fastapi app to add routes to

  • function_specs – FunctionSpecStore with function specifications

  • page_title – Title for the web interface

  • custom_css – Optional custom CSS

  • rjsf_theme – RJSF theme to use

Note

This function detects whether the app is using Bottle or FastAPI and adds routes accordingly.
